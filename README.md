# Vectorized Biomedical Calculation

## Project Description

## Installation
### Requirements
* Python: >= 3.14
* NumPy: Numerical computations and vectorized operations
* Matplotlib: Data visualization
* ipykernel: Running and developing Jupyter notebooks
* timeit: Measuring and comparing execution times

### Setup
1. Clone repository
2. Navigate to the project directory
3. Create a virtual environment
'python -m venv .venv'
4. Activate the virtual environment
'.venv\Scripts\activate'
5. Install required dependencies
'python -m pip install numpy matplotlib ipykernel'

## Usage
Run the project using the Jupyter notebook 'notebooks\synthetic_lab.ipynb'

## Testing
'numpy.testing' is used to perform numerical testing of certain arrays in the notebook.

'timeit' is also used to measure and compare execution times.
